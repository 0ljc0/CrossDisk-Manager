## 读取与展示边界

- 文本默认 2 MiB + 最多 1 字节探测；查看更多是显式操作，最高 8 MiB；字符预算 25 万至 100 万，行数预算 1 万至 4 万。长文件不会自动完整读入。
- 图片数据 16 MiB，1600 万像素，单边 16384；Qt 每次图片分配限制 64 MiB。缩略图最多 1024×768、4 MiB PNG，主进程再次检查，不放大超过缩略图像素尺寸。
- 解码、读取、缩略图生成都在可终止子进程中，切换文件只保留最新请求，窗口不会等待同步文件读取。预览子进程禁止 Python 字节码缓存。
- 原文件只通过 open_read 访问；UI 文本控件 readOnly=True，无编辑/保存/执行按钮，不通过系统文件关联打开未知文件。

## 遗留限制

- 真实 Ubuntu 分区的 /home 文本仍待人工验收；本次没有自动读取真实 Ubuntu 文件，不能把合成镜像证据当成实盘验收。
- 权限不足时仍需用户显式使用独立读取工具；未增加管理员代理 IPC 或自动提权。
- 自动编码检测不保证识别全部无 BOM 编码；不确定时明确失败并让用户手选，二进制拒绝规则仍生效。
- 文本达到最大安全展示预算后不提供无限加载或编辑；图片仅首帧静态缩略图，不提供原图无限放大、外部打开或动态播放。
- Qt 的单次图像分配限制不是整个进程 RSS 上限；复杂/恶意解码的超时与失败会回收读取进程。未实测所有相机、色彩配置或损坏文件变体。
- 未格式化磁盘、修改分区表、挂载系统盘、写原始扇区或写入 Ubuntu/EFI/Recovery。没有源文件隐藏临时缓存。
