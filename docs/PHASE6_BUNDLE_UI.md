# ext4 暂存与修改包界面

2026-11-07。主窗口新增“ext4 暂存与修改包…”入口。

使用流程：

1. 选择可只读浏览的 ext4 分区，进入专用用户数据目录。分区根目录、未完成读取或读取失败时不能创建暂存会话。
2. 点击“ext4 暂存与修改包…”，当前目录成为本会话范围；每个分区同时仅保留一个会话，后续点击返回该会话。
3. 输入相对路径。新建文件和替换内容通过选择本地文件导入；文本可先在本地编辑再导入。新建目录、暂存删除及同目录重命名也在面板完成。新建 UID/GID 和文件/目录权限可分别选择，默认值需用户核对；Ubuntu 端仍按独立注册策略授权。
4. 操作列表显示待创建、待修改、待删除和待重命名。主文件列表已有条目的“访问状态”显示对应暂存状态；尚不存在的文件仅出现在待应用面板，不混入真实磁盘列表。
5. 选中操作可取消。导出选择父目录并输入一个尚不存在的新目录名，软件不覆盖已有目录。
6. 关闭未导出的草稿必须确认；导出后修改又会要求重新导出或确认丢弃。会话内容不自动恢复。

所有源打开、快照、哈希及修改包导出均在后台线程执行，每次操作重新验证分区身份。正在工作时关闭被拒绝，等待线程完成后可再次关闭；不强行终止底层读取。任务失败保留已有草稿并显示原因。

主窗口分区写入权限保持 false，原来的直接写按钮未解锁。面板始终提示“仅本地暂存，Ubuntu 尚未修改”。Windows 本地工作目录位于应用配置目录旁的 pending-bundles 下，关闭只清理会话自己的文件，导出包独立保留。

测试覆盖：真实 Qt 窗口与 ext4 镜像，暂存替换、新建、导出、包校验、失败保护、取消、文件列表状态、未导出关闭确认及源镜像哈希不变。Ubuntu 正式 apply 和恢复命令尚未开放，本轮不要求跨系统重启验证。
