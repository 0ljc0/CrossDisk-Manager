## 证据分层

- 真实硬件只读：本机 Windows 清单、C:\Users、D 盘项目浏览、属性、预览与限定范围搜索。没有自动读取真实 Ubuntu 文件。
- Windows 隔离写入：pytest 临时目录、项目新建临时目录和 D:\CrossDisk_TestWrite 内独占新临时子目录，覆盖复制、冲突、保存备份、重命名/移动/删除；没有修改既有用户文件或系统目录。
- ext4 隔离镜像：合成普通镜像经真实 pytsk3 解析，验证浏览/预览/搜索/导出及散列不变；**不是 ext4 写入兼容验证**。
- Mock/故障注入：错盘、保护分类、驱动缺失、无权限、空间不足、超时/取消、短读/替换失败、旧请求；中断模拟不等于真实突然断电恢复测试。
- 待人工：真实 Ubuntu /home 浏览/搜索/导出、回收站原生确认和恢复、独立 Windows 10/其他 Windows 11、UNC、热插拔、多物理盘及断电恢复。ext4 写入既未执行也未开放。
