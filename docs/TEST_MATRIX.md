# 跨分区能力与风险测试矩阵

| 类别 | 发现分区 | 浏览文件 | 导出至 Windows | 在源分区写入 | 备注 |
|---|---|---|---|---|---|
| NTFS/FAT32/exFAT 普通数据卷 | 是 | 是，受 Windows 权限约束 | 是 | 是，受 Windows 权限约束 | 已挂载、可访问时 |
| Ubuntu ext4（未加密） | 是 | 目标 | 目标 | 默认禁用，任务 11 验证后按条件开放 | 使用 pytsk3 只读；写入需另行验证 |
| EFI 系统分区 | 是 | 有能力时受限只读 | 有能力时导出 | **禁止普通模式写入** | 引导相关 |
| MSR 保留分区 | 是 | 否 | 否 | 否 | 不是普通文件卷 |
| Recovery 恢复分区 | 是 | 有能力时受限只读 | 可选 | **禁止普通模式写入** | 系统恢复相关 |
| BitLocker/LUKS 未解锁 | 是 | 否 | 否 | 否 | 不绕过加密 |
| Btrfs/XFS/未知文件系统 | 是 | 依适配器 | 依适配器 | 默认禁用 | 禁止假设可读写 |
| 已损坏或离线设备 | 尽力 | 可能无法 | 可能无法 | 否 | 保护源数据 |

## 必须覆盖的错误场景

1. 管理员权限不足、锁定磁盘、设备断开、卷标变化/盘号变化、GPT 分区编号变化。
2. 文件系统无法解析、ext4 特性不兼容、编码损坏、软链接循环、路径穿越攻击。
3. 同名目标文件冲突、磁盘满、操作中断、文件正在被另一程序修改、文件超过预览阈值。
4. 复制结束核对字节数/校验；不能将中途失败的临时文件当作已成功文件。
5. 所有写操作必须对受保护分区**从 UI 到后端都拒绝**，不能只靠灰色按钮。

## 安全验证目标

- 在空白测试目录验证 Windows 写操作。
- 在可丢弃 ext4 镜像或独立测试盘验证任何 ext4 写操作；不得使用真实 Ubuntu 系统分区进行破坏性测试。
- 每轮记录测试时间、命令、结果、风险，不能虚构通过结果。
