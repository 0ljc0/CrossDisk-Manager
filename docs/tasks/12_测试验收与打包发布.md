## 一、任务目标

## 二、必须实现的内容

1. 检查模块边界、类型、日志、后台线程清理、长路径、中文路径、权限拒绝、文件大小/磁盘空间边界。

4. 实现必要的错误弹窗与日志查看，保护隐私（日志不写入文件内容、令牌和敏感路径的完整信息）。
5. 使用 PyInstaller 或等效成熟打包方案生成 Windows 可执行程序；确保普通用户可启动，按需提示管理员权限，而非强制全局提权。
