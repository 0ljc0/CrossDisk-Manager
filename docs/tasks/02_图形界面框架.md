# 任务 02｜三栏图形化界面与基础交互

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 01 已验收。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

在不访问真实磁盘的前提下完成中文 Windows 桌面文件管理器主界面。

## 二、必须实现的内容

1. 使用 PySide6 建立主窗口：菜单/工具栏、左分区树、中间文件表、右侧属性预览、底部任务状态栏。
2. 展示导航栏：后退、前进、向上、刷新、地址路径、搜索入口；按钮接回调而非空摆设。
3. 先使用 mock 数据演示 C:、D:、Ubuntu（只读）、EFI（受保护）、Recovery（受保护）、MSR（不可浏览）。
4. 显示“可读写/只读/受保护/需要管理员/不可识别”状态；根据能力自动禁用新建、重命名、删除、保存等按钮。
5. 双击文件夹模拟进入；空目录、磁盘不可访问、加载中等状态有可理解的页面。
6. 菜单实现主题切换、窗口尺寸记忆，优先适配 1080p/2K/4K、高 DPI、中文长文件名。
7. GUI 组件使用明确的 Model/View 接口，为将来替换 mock 数据留下扩展点。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 本阶段不调用管理员权限、真实硬盘或 ext4。

## 四、验收清单

- 运行 `python -m app.main`，截图/检查三栏布局，无文字错位。
- 点击分区和模拟文件夹，地址栏和文件列表同步变化。
- 切换只读与保护 mock 分区，写入按钮保持灰色且说明原因。
- 重启后主题/窗口尺寸正确恢复；不得访问 `PhysicalDrive`。
