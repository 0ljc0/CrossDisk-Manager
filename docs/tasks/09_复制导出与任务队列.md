# 任务 09｜安全的文件复制与批量导出

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 08 已验收。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

从 Windows 或 Ubuntu 只读源选择文件/目录，向有写权限的 Windows 目标复制、批量导出。

## 二、必须实现的内容

1. 定义统一 `CopyJob`/`ExportJob`、任务状态与后台队列，支持进度、暂停/取消（如果可行）、重试与错误说明。
2. 输入为来源虚拟路径、目标 Windows 路径与冲突策略；默认遇到目标已存在时跳过或提示，不自动覆盖。
3. 实现流式分块读取、目标临时文件落盘、写入完毕并核对字节数后原子替换**该任务新创建的临时目标**；确保取消/异常时不留下伪装完整的文件。
4. 初期仅支持 Ubuntu → Windows 导出、Windows → Windows 复制，不能通过复制接口实现 Windows → Ubuntu 写入。
5. 源遍历要限制符号链接行为，避免把同一个目录重复复制或触达系统路径。
6. 显示任务进度、已完成/失败计数、总字节；检查 Windows 目标空间与可写权限。
7. 文件时间戳与属性保存仅在后端支持时提供，冲突时明确给用户选择。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 不得将临时文件建在 Ubuntu 分区或系统关键目录中；不得在取消后删除既有目标。

## 四、验收清单

- Ubuntu `/home` 中测试目录导出到 `D:\CrossDisk_TestExport`，核对源和目标的字节/哈希。
- 目标已存在时默认不得覆盖；缺空间或无权限时中止并告知原因。
- 大文件复制中取消后，不出现被误认为完整的目标文件。
- UI 在复制时仍可浏览目录；写入 Ubuntu 的选择入口保持禁用。
