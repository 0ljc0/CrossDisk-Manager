# 任务 05｜Ubuntu ext4 只读访问与自动定位

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 04 已验收。

## 一、任务目标

把已经验证的 pytsk3 CLI 能力封装为 GUI 可调用的 Ubuntu 只读后端。

## 二、必须实现的内容

1. 参考已有脚本 `D:\谷歌浏览器\read_ubuntu_partition6.py`（若存在，先阅读再复制适配，不得修改原脚本）。
2. 编写 `Ext4ReadOnlyBackend`，通过扫描所得 `DiskPath + PartitionOffset` 访问 `pytsk3.Img_Info(...), FS_Info(...,offset=...)`，以当前物理磁盘号+分区偏移为单次访问参数，不将 `0/6` 硬编码在业务逻辑中。
3. 必须先核对分区身份与文件系统探测结果；若是 LUKS/LVM/未知格式或检测失败则停止、提示后端不支持。
4. 实现 `list_dir`、`stat`、`open_read` 的流式读取接口以及 `close` 资源清理；忽略 `.`、`..`，处理文件名编码、符号链接、损坏 inode 与读取失败。
5. 源后端不含 `write`、`rename`、`remove`，能力声明必须 `read=True, write=False`。
6. 权限不足时提示使用管理员权限的独立读取进程方案；避免默认以管理员身份运行整个 GUI。
7. 测试优先使用可丢弃 ext4 镜像文件（含测试文件）和只读自动化测试；真实分区仅人工只读验收。
