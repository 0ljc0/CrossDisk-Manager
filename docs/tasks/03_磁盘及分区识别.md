# 任务 03｜自动扫描本机全部物理磁盘与分区

> 建议一次 Claude Code 会话只完成此任务。

## 一、任务目标

自动列举所有物理磁盘、GPT 分区和 Windows 卷，将其展示在左栏。

## 二、必须实现的内容

1. 封装 `DiskInventoryService`；Windows Storage/CIM 或 PowerShell `Get-Disk`, `Get-Partition`, `Get-Volume` 可作第一实现，PowerShell 命令必须固定，不能拼接未经转义的用户输入。
2. 信息至少包含：磁盘编号、设备型号、容量、分区编号、GPT Type GUID、Partition GUID（可获取时）、起始 Offset、Size、IsHidden、DriveLetter、卷标、文件系统、状态。
3. 先以结构化 JSON 输出再解析，注意 PowerShell 单对象/数组的差异、空盘符/空卷、权限失败以及扫描超时。
4. 用 `DiskId` + 稳定标识和 `PartitionId` + GPT GUID/位置组合标识分区；不要仅依赖 `DiskNumber=0, PartitionNumber=6`。
5. 标准显示不支持的/无文件系统的分区，不要假设 `Unknown=True` 就是 ext4，不能凭容量判断类型。
6. 按分区类别标记 EFI、MSR、Recovery、普通数据；系统保护策略优先于用户对分区的昵称。
7. 扫描采用后台线程或 worker；有刷新功能，扫描失败不能卡住 UI。

## 四、验收清单

- 在用户本机的 YMTC 953.87GiB 磁盘上应识别 6 个分区（包含 150GiB Ubuntu 目标）；序号按真实扫描结果。
- 通过 `Get-Partition | Format-Table ...` 与 GUI 数据人工核对大小和偏移。
- 模拟无盘符分区、未插入的盘、PowerShell 不存在和权限拒绝，界面显示明确错误。
- 整个任务没有调用任何物理磁盘写 API。
