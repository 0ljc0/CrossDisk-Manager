# 任务 08｜跨 Windows/ext4 搜索及筛选

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 07 已验收。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

添加按文件名、扩展名、路径和文件类型搜索，先实现即时扫描，索引作为可选项。

## 二、必须实现的内容

1. 文件列表加即时筛选（仅作用当前目录）；全局搜索可选择当前分区或已识别、可读的全部分区。
2. 搜索内容先限定为文件名/目录名、扩展名、大小/日期等属性，不做无界全文检索。
3. 支持进度、取消、结果数、路径定位、错误目录统计；每种后端都按其权限与路径语义递归迭代。
4. 防止符号链接循环、非常深的目录结构、不可读目录造成死循环；默认不跟随目录链接越界。
5. 结果按来源分区显示，双击定位对应目录，切换源分区不使用过期的分区号。
6. 可选建立 SQLite 元数据索引（只能写入 Windows 用户目录），必须允许关闭/清空，默认不索引文件内容。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 不实现自动后台监控整个磁盘，不上传任何用户文件到网络。

## 四、验收清单

- 在 C/D 盘和 Ubuntu `/home` 中按 `*.py` 查询，能显示归属分区与路径。
- 中途点击取消，后台任务停止且 GUI 正常响应。
- 模拟无权限目录，搜索显示部分成功与跳过原因，不能假装全部扫描成功。
- 生成的索引、日志只存在于 Windows 配置目录，不写 Ubuntu。
