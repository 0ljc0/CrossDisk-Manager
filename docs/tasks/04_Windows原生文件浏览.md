# 任务 04｜Windows 文件系统只读浏览

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 03 已验收。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

实现 Windows 正常盘符和已挂载卷的目录浏览、属性读取；暂不写入。

## 二、必须实现的内容

1. 实现 `NativeWindowsBackend`：`list_dir`、`stat`、`open_read`、`get_capabilities`，先只返回只读能力。
2. 支持普通盘符、用户有权访问的 UNC 路径、必要时 Volume GUID 路径；不要尝试绕过 Windows 权限。
3. 处理中文、空格、超长路径、隐藏文件、软连接、无权限、被占用文件、符号链接循环。
4. 文件属性包括大小、类型、修改时间、是否目录、读写权限（供展示但不等同于实际授权）。
5. 目录项只在点击目录时加载，超大目录分页/分批展示；UI 主线程禁止执行递归扫描。
6. 将目录结果映射到 `FileEntry` 通用模型，文件图标与表头显示正确。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 本阶段仅为 Windows 后端添加只读接口，不能实现 `unlink()` / `write_text()`。

## 四、验收清单

- 能浏览 `C:\Users`、D 盘用户目录，双击文件夹并返回。
- 无权限路径显示“访问被拒绝”，程序不中断；显示 Windows 隐藏文件开关效果。
- 对大量文件目录无界面假死；不存在路径给出清晰提示。
- 新建、覆盖、删除按钮仍然禁用，且没有写入测试。
