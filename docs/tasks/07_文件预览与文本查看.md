# 任务 07｜代码、文本和图片安全预览

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：任务 06 已验收。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

在右侧面板查看文本/代码/图片及元数据，预览绝不改变源文件。

## 二、必须实现的内容

1. 设计预览服务：文本 `txt/md/py/json/yaml/log/csv`，图片 `png/jpg/jpeg/bmp/webp`（按 Qt/解码库实际支持），未知类型显示属性与不支持提示。
2. 仅按文件头与大小限制加载：例如文本预览默认最多 2 MiB、图片按像素和数据上限防止内存耗尽；用户可选择查看更多，但不自动读完整大文件。
3. 文本检测 UTF-8、UTF-8 BOM、UTF-16，支持手选编码，二进制不直接当作文本输出。
4. 图片读取或生成缩略图在后台完成，切换文件时能取消上一次请求。
5. 展示文件来源分区、相对路径、大小、修改时间与只读状态；右侧“编辑”按钮仅在写能力被真正开放后出现。
6. 预览异常、文件损坏、权限拒绝要友好处理，不应造成应用退出。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 禁止静默执行脚本、打开可执行程序或对源文件生成隐藏临时文件。

## 四、验收清单

- 可预览 D 盘上的 `.py`/`.md` 与 Ubuntu `/home` 下的小文本文件。
- 大于阈值的文本提示“预览已截断”，不能直接占满内存。
- 双击二进制文件不会乱码覆盖、弹出危险执行，也不会在源分区写缓存。
- 预览时用检查工具确认未对源文件执行写操作。
