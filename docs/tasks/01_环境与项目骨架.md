# 任务 01｜环境搭建、工程结构与最小启动

> 建议一次 Claude Code 会话只完成此任务。  
> 前置条件：无，首次运行。  
> 本次交付：代码/测试/进度文档，不需要在此次会话提前开发后续功能。

## 一、任务目标

实现一个能在 Windows 正常启动的 Python/PySide6 工程，为后续模块提供稳定结构。

## 二、必须实现的内容

1. 创建 Python 3.11/3.12 虚拟环境与 `requirements.txt`；优先固定经验证依赖版本，可先包含 PySide6、pytest，pytsk3 可延至任务 05 安装。
2. 建立 `app/main.py`、`app/core/`、`app/ui/`、`app/backends/`、`app/services/`、`app/jobs/`、`tests/`、`docs/`，确保包结构明确。
3. 实现异常日志目录（例如用户可写的 `%LOCALAPPDATA%/CrossDiskManager/logs`），不能把日志写在系统保护目录。
4. 建立配置管理：主题、语言、窗口大小、是否显示隐藏文件；默认安全模式为只读。
5. 实现最小 PySide6 主窗口、中文标题、退出处理，创建 README 及 `.gitignore`，生成 `docs/PROGRESS.md`。
6. 准备 `python -m app.main` 作为统一启动方式，确保不需要以管理员权限启动 GUI。

## 三、交付文件与约束

- 修改/新增对应的 `app/` 模块，补充至少一个本阶段直接相关的 `tests/` 用例。
- 更新项目 `README.md`（运行方法变化时）和 `docs/PROGRESS.md`（本任务完成情况、下一步待办）。
- 不改变其他模块公共接口；如确实需要，记录迁移说明并修复调用者。
- **专门禁令：** 禁止添加磁盘扫描和任何写入逻辑。

## 四、验收清单

- 在普通 PowerShell 中执行 `py -m venv .venv`。
- 执行 `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`。
- 执行 `.\.venv\Scripts\python.exe -m app.main`，出现窗口，能关闭。
- ` .\.venv\Scripts\python.exe -m pytest -q` 运行基础测试且无失败。
- 从任何工作目录调用 `...\python.exe -m app.main` 时需注明从项目根目录启动的要求或配置包路径。
