# CrossDisk Manager（跨盘管理器）需求与使用规范 v1.0

> 文档性质：Windows 桌面软件需求说明（初版）  
> 目标平台：Windows 10/11 x64  
> 软件定位：在统一图形界面中发现和浏览本机各磁盘分区，按文件系统能力安全读取、复制、编辑及管理文件。  
> 核心原则：**全部分区可发现；有受支持文件系统的分区可浏览；仅在明确支持、已解锁、权限允许且安全检查通过时才可写入。**

## 一、项目背景与目标

用户使用 Windows + Ubuntu 双系统。当前 Windows 主机的一块约 953.87 GiB YMTC SSD（磁盘 0）包含如下分区：

| 当前分区 | 容量（约） | 文件系统/用途 | 预期软件能力 |
|---|---:|---|---|
| 磁盘0-分区1 | 260 MiB | EFI System | 识别、只读浏览（在可安全访问时） |
| 磁盘0-分区2 | 16 MiB | MSR Reserved | 显示分区信息，不提供文件浏览 |
| 磁盘0-分区3 | 300 GiB | Windows C:，NTFS | 正常浏览与授权文件操作 |
| 磁盘0-分区4 | 501.64 GiB | Windows D:，NTFS | 正常浏览与授权文件操作 |
| 磁盘0-分区6 | 150 GiB | Ubuntu，预期 ext4 | 只读浏览起步；经驱动适配与验证后启用读写 |
| 磁盘0-分区5 | 1.95 GiB | Windows Recovery，NTFS | 识别、默认只读；禁止日常修改 |

分区序号与磁盘物理排列顺序不一定一致。软件不能仅凭“磁盘0、分区6”硬编码位置，必须根据设备标识、GPT 分区 GUID、偏移量等重新确认对象。

**目标：**

1. 扫描所有连接的物理磁盘、分区及卷，包括无盘符、隐藏分区和外置磁盘。
2. 以接近 Windows 文件资源管理器的体验显示目录、文件、属性与预览。
3. 支持 Windows 目录与 Linux 目录之间复制、批量导入、导出和查找。
4. 对可安全写入的文件系统提供新增、修改、重命名、移动、删除等操作。
5. 将系统关键分区、加密分区、未知文件系统及不兼容情况明确标记，避免误操作。
6. 中文界面优先，提供任务进度、错误解释、日志及必要的恢复机制。

## 二、适用范围与边界

“管理所有分区”指**发现并展示所有分区**，不等于**对每个分区都强制读写**。

| 文件系统或分区类型 | 第一版 | 后续扩展 | 说明 |
|---|---|---|---|
| NTFS / FAT32 / exFAT | 原生读写 | 维持 | 遵循 Windows 权限与文件占用限制 |
| ext4 | 只读浏览、导出 | 读写（受控开启） | 需要成熟的 ext4 写入驱动或可靠后端 |
| ext2 / ext3 | 按已接入后端能力 | 可选读写 | 需逐项验证特性兼容性 |
| Btrfs / XFS | 暂不承诺 | 可选只读支持 | 不能因为能读就认定能写 |
| LVM / LUKS / BitLocker | 识别、显示锁定状态 | 经明确授权、合法解锁并有适配器时访问 | 不内置绕过加密机制 |
| EFI / Recovery | 显示、默认只读 | 只在专门维护模式中按严格权限处理 | 普通用户界面不允许写入 |
| MSR / 未分配空间 | 展示元数据 | 无普通文件管理功能 | 无可直接浏览的常规文件树 |
| 未知、损坏或不受支持的文件系统 | 只显示诊断信息 | 增加解析适配器 | 禁止盲目写入 |

特别限制：Windows 与 Ubuntu 位于同一块正在运行 Windows 的物理系统盘上。不能把 `wsl --mount` 作为默认解决方案；该命令无法附加 Windows 正在使用的系统磁盘。不得尝试将系统盘离线来规避限制。

## 三、主要界面布局

建议采用经典三栏式 Windows 桌面软件，并支持暗色/浅色主题、中文路径及高 DPI 缩放。

│                 │                                    │                     │
│ ▼ 磁盘0  YMTC   │ 文件名       大小  类型   修改时间  │ 名称：robot_learning│
│   EFI 260MB 🔒  │ ────────────────────────────────   │ 类型：目录          │
│   MSR 16MB —    │ 📁 ljc                             │ 文件系统：ext4      │
│   Windows C:    │ 📁 lost+found                      │ 当前模式：只读      │
│   Data D:       │                                    │ 可用操作：导出      │

│ ▶ 其他磁盘      │                                    │                     │
├─────────────────┴────────────────────────────────────┴─────────────────────┤
│ [返回] [刷新] [复制] [导出] [粘贴] [新建] [重命名] [删除] [安全模式设置]    │

设计要求：
- 左侧显示按物理磁盘分组的分区树；有盘符显示盘符，无盘符显示用途、文件系统、容量与自定义名称。
- 中间显示目录文件表格，包含名称、大小、类型、修改时间、权限、属主（Linux 可用时）。支持排序、筛选、面包屑导航、后退/前进和标签页。
- 右侧显示分区及文件属性、文本/图片预览、符号链接目标、读写能力及风险说明。
- 底部显示任务队列、当前传输速度、进度、错误和操作日志。
- 标识访问状态：可读写、只读、锁定、需要管理员、不可识别；不以“隐藏”直接推断是否可读写。
- 不支持的按钮明确禁用，鼠标悬停说明原因，不提供虚假的“写入成功”。

## 四、主要功能及使用方式

### 4.1 磁盘与分区发现

用户点击「扫描磁盘」：
1. 列出所有物理磁盘、容量、连接类型、健康状态（能获取时）及 GPT/MBR 分区信息。
2. 列出每个分区的分区 GUID、起始偏移、大小、卷路径、盘符、分区类型和识别出的文件系统。
3. 隐藏分区、Linux 分区与恢复分区都显示；磁盘热插拔后可刷新。
4. 为每个分区显示实际可用能力；不可识别时只展示诊断信息。

### 4.2 文件浏览与预览

用户在左侧选择 Ubuntu 分区，双击 `/home/ljc/robot_learning`：
1. 列出该目录下文件和文件夹；可进入子目录或返回上级。
2. 单击 `.py`、`.txt`、`.json`、`.yaml`、`.md` 等可预览文本；图片格式可显示缩略图。
3. 大文件采用分页/流式读取，禁止一次加载整文件；二进制文件默认只展示基础属性。
4. 支持 Unicode 文件名、隐藏文件、Linux 权限展示，明确区分普通文件、目录和软链接。

### 4.3 复制、导入、导出

- Ubuntu → Windows：选择文件或目录 →「导出」→ 选择 `D:\UbuntuBackup` → 显示进度与完成校验。
- Windows → Ubuntu：仅 ext4 写入后端通过兼容性检查并进入读写模式时允许「导入」。
- 支持多选、拖拽、剪贴板复制、目录递归复制、暂停/取消，以及覆盖、跳过、保留两份等冲突策略。
- 默认跨分区拖拽执行“复制”，不直接删除源文件；移动需额外确认。
- 支持核对文件大小、可选 SHA-256；失败时保留可追踪的任务记录，避免半写入文件被误认为完成。

### 4.4 新建、修改与删除

仅当目标分区为**可写、已解锁、未受保护**时启用：
- 新建文件/文件夹、重命名、移动、删除。
- 内置轻量文本编辑器：读取 → 预览 → 编辑 → 比较差异 → 创建备份 → 保存 → 验证。
- 对 Linux 可执行脚本与配置文件提示权限、属主、换行符及符号链接差异；不擅自改变 Linux 权限位。
- 删除默认为「先确认、后执行」，系统分区或大批量删除需要二次确认；无法提供回收站的文件系统必须提示“可能永久删除”。
- **第一版禁用在 Ubuntu ext4 中写入**；只读工具 `pytsk3` 不负责创建/删除/修改 ext4 文件，不能把文件字节直接写回原始扇区冒充完整的文件系统写入。

### 4.5 文件搜索

可按磁盘、分区、目录范围搜索：文件名、扩展名、大小、修改时间，后续支持文本内容检索。
- 优先实时遍历；可选建立本地索引，但索引不能绕过文件访问权限。
- 搜索结果显示完整路径、分区、读写状态，可跳转定位或导出。
- 对软链接、循环目录与无权限路径设置跳过和明确提示。

### 4.6 文件与分区信息

- 文件：名称、大小、时间、类型、所在分区、权限、所有者（可解析时）、校验值。
- 分区：设备唯一标识、文件系统、容量、可用空间（可查询时）、隐藏状态、挂载状态、加密状态、驱动兼容性及当前访问模式。
- 显示原始字节单位与人类易读单位，明确 GB/GiB 差异。

### 4.7 任务、日志及错误恢复

- 任务中心：队列、进度、已复制字节、速度、预计剩余时间（能估算时）、暂停、取消、重试。
- 日志内容：时间、源与目标、操作类型、分区标识、结果、错误码；默认不记录文件正文与敏感内容。
- 修改前可选自动备份至 NTFS 数据盘，保存版本、时间和原始路径；备份不可保证跨文件系统原地回滚，恢复需明确操作。
- 文件系统不一致、断电中断、加密未解锁、写入后端不兼容时立即停止写入并给出说明。

## 五、安全策略（强制要求）

1. **默认只读**：首次发现的分区均以只读方式进入；读写模式必须手动启用且通过检查。
2. **按分区授权**：对 C:/D: 的文件操作遵循 Windows ACL 和文件占用限制；敏感操作按需请求 UAC，而不是让整个 GUI 持续以管理员运行。
3. **系统分区保护**：EFI、MSR、Windows Recovery 等不提供常规写入按钮；不提供格式化、删除分区、修改分区表等危险操作。
4. **禁止盲写原始扇区**：原始磁盘句柄仅允许在明确的只读扫描/解析适配器中使用；文件写入必须经支持该文件系统的可靠驱动或后端。
5. **写前确认**：显示目标文件、目标分区、操作清单、潜在覆盖、权限变更、预计空间需求和备份状态。
6. **避免并发损坏**：重检分区身份、写入后端状态、卷是否已挂载/锁定、Ubuntu 文件系统是否处于可安全写入的状态；无法确认时拒绝写入。
7. **安全落盘**：使用临时文件加校验、适用时原子替换/刷新；跨分区移动先复制校验，再请求删除源文件。
8. **加密尊重**：BitLocker、LUKS 等需要合法凭据及对应解锁后端，绝不通过绕过身份验证获取内容。
9. **兼容性优先**：ext4 写入先在测试镜像和非关键分区验证特性（日志、64bit、metadata_csum 等）；不兼容则降级只读。
10. **权限透明**：管理员权限不等于具有所有受保护文件的安全修改权限；UI 必须区分“无权限”和“不支持”。

## 六、技术方案建议

| 软件层 | 推荐技术 | 用途 |
|---|---|---|
| 桌面 UI | Python 3.12 + PySide6（Qt） | 快速开发 Windows 图形界面 |
| Windows 分区发现 | PowerShell Storage Cmdlets 原型；正式版可接 Windows Storage API/WMI | 列出物理磁盘、分区、卷及相关信息 |
| Windows 文件操作 | Python `pathlib`/`shutil` + Win32 API | NTFS/FAT/exFAT 原生读写 |
| Linux 分区只读 | 现有 `pytsk3` 脚本封装成适配器 | ext4 文件树、只读提取 |
| Linux 分区读写 | 经过授权的成熟 ext4 文件系统驱动/服务及其访问接口 | 读写能力须按驱动、版本、文件系统特性验证 |
| 后台任务 | Qt 工作线程/任务队列 | 防止扫描和复制阻塞主界面 |
| 日志与设置 | SQLite + JSON 配置 | 索引（可选）、操作记录、偏好设置 |
| 发布 | PyInstaller 或 Nuitka + 安装包 | 打包 Windows x64 桌面程序；第三方驱动单独按许可安装 |

**建议结构：**

```text
CrossDiskManager/
├─ app.py                   # 程序入口
├─ ui/                      # 主窗口、文件表格、分区树、预览、对话框
├─ core/
│  ├─ disk_discovery.py     # 分区扫描、身份确认
│  ├─ fs_adapter.py         # 文件系统统一接口
│  ├─ windows_fs.py         # Windows 原生文件操作
│  ├─ ext4_reader.py        # pytsk3 只读适配器
│  ├─ ext4_writer.py        # 经验证后才接入的写入后端
│  ├─ file_tasks.py         # 复制/搜索/导出/取消
│  ├─ preview.py            # 文件预览
│  └─ policy.py             # 写入能力检查和安全策略
├─ services/                # 需要提权的独立受控服务（后期）
├─ storage/                 # 配置、日志、可选索引
└─ tests/                   # 临时镜像、单元测试、集成测试
```

文件系统适配器统一约定：`probe()`、`list_dir()`、`stat()`、`read_stream()`、`capabilities()`；可写实现按需增加 `create()`、`write_stream()`、`rename()`、`delete()`，所有写入在调用前统一经过 `policy.py`。

## 七、用户常见操作流程

**场景 A：在 Windows 读取 Ubuntu 的 ROS2 项目**

启动 → 扫描磁盘 → 选「磁盘0 / Ubuntu 150GB」→ 浏览 `/home/ljc/robot_learning` → 选择代码文件 → 预览，或导出到 `D:\UbuntuBackup\robot_learning`。

**场景 B：把 Windows 文件复制到 Ubuntu**

先确认驱动已安装、目标 ext4 特性兼容且已显式启用读写 → 选择 D 盘文件 → 复制 → 打开 Ubuntu 目标目录 → 粘贴 → 确认目标与备份策略 → 完成校验。未启用读写时按钮禁用。

**场景 C：直接编辑 Ubuntu Python 脚本**

打开脚本 → 在编辑器修改 → 查看差异 → 先保存备份到 D 盘 → 通过受支持的 ext4 写入后端保存 → 再次读取比对。失败时维持只读并保留备份；不能直接用原始磁盘写入。

**场景 D：查看隐藏分区**

磁盘树选择 EFI/Recovery → 查看属性和可用的只读内容；对 MSR 仅展示分区信息。系统保护分区不显示“删除/覆盖”常规操作。

## 八、开发计划和验收标准

### V0.1：可用原型（先做）
- PySide6 主界面、所有磁盘分区树、NTFS 浏览、ext4 只读目录浏览。
- 双击进入目录、路径栏、刷新、查看属性、文本预览。
- 使用当前 `pytsk3` 脚本成果，不动 ext4 写入。

### V0.2：实用文件管理器
- 全分区文件搜索、单/批量导出、跨分区复制到 Windows、进度、取消、日志。
- Windows NTFS/FAT/exFAT 原生文件新增、修改、删除（依权限）。
- 完善路径、Unicode、符号链接、错误处理与分区热插拔。

### V0.3：Ubuntu ext4 受控写入
- 引入可合法使用的成熟 ext4 读写后端，先在**测试镜像/备用磁盘**验证；加入能力检测和写入确认。
- 经充分验证后，逐步允许向 Ubuntu 非系统目录复制/编辑文件；系统目录维持保护。
- 一旦检测到不兼容 ext4 特性、卷状态不明或写入风险，立即退回只读。

### V1.0：正式桌面应用
- 安装与卸载、应用设置、主题/高 DPI、多语言预留、任务历史、错误诊断。
- 发布前完成跨文件系统复制正确性、异常中断恢复、写入数据完整性与权限测试。

**最低验收用例：**
1. 软件正确显示当前物理磁盘的 6 个分区，正确区分无盘符 ext4、EFI、MSR、Recovery。
2. 不用启动 Ubuntu，在 Windows 中浏览 `/home/ljc/robot_learning`，并导出一个文件且校验一致。
3. 可在 D 盘创建/重命名/编辑测试文件并显示成功日志。
4. ext4 未配置受支持写入后端时，所有写入按钮严格禁用。
5. EFI/Recovery/MSR 默认不可写；加密和未知文件系统不能被误判为普通可写盘。
6. 中断复制、源文件占用、盘符变化和权限不足均有明确反馈，不损坏源文件。

## 九、不纳入第一版的功能

- 格式化、分区扩容、修改 GPT/MBR、修复引导、写入硬盘原始扇区。
- 自动破解 BitLocker/LUKS 或跳过操作系统权限。
- 对不支持的文件系统承诺“强制写入”。
- 对当前正在使用的系统盘执行 `wsl --mount`、离线整盘或强制卸载。
